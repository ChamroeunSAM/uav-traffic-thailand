# Paper figures

Generated by `scripts/make_paper_figures.py` (one figure per positional arg).
Each writes a PNG (inspection) and a PDF (manuscript). Examples:

    python scripts/make_paper_figures.py scenes        # F2 scene gallery
    python scripts/make_paper_figures.py detectors     # F3 accuracy vs speed
    python scripts/make_paper_figures.py boxvstraj     # F4
    python scripts/make_paper_figures.py smoothing     # F5
    python scripts/make_paper_figures.py accel         # F6a
    python scripts/make_paper_figures.py jerk          # F6b
    python scripts/make_paper_figures.py f7_0006_1min  # F7 overlay (per clip)
    python scripts/make_paper_figures.py compare_0041_5min  # F7compare
    python scripts/make_paper_figures.py calibration   # F8
    python scripts/make_paper_figures.py gtfree        # F9
    python scripts/make_paper_figures.py ablation      # F10  domain-gradient bars
    python scripts/make_paper_figures.py ablation_line # F10b domain-gradient lines
    python scripts/make_paper_figures.py sf1           # SF1 detector Grad-CAM (random frames)
    python scripts/make_paper_figures.py sf1_eigen     # SF1 EigenCAM variant (same frames)
    python scripts/make_paper_figures.py sf2           # SF2 detector Grad-CAM (selected frames)

Notes:
- F6a/F6b are matched panels for manual side-by-side paneling.
- F6/F4 distributions POOL all samples across clips (sample-weighted); the
  per-clip-averaged numbers in Tables T5/T5b are clip-weighted, so small numeric
  differences between figure annotations and tables are expected and correct.
- F7compare ID-jump counts match the extraction's teleport counts exactly
  (0041: 67 vs 175; 0001: 93 vs 239) — impossible world-speed across ≤15-frame
  gaps. Even the clean tracker has dozens over 5 dense minutes; frame as
  *relative* quality (~2.6× fewer), not error-free vs broken.
- Figure-level titles are omitted (manuscript supplies captions); per-panel
  subplot titles are kept in F2 (scenes) and F9 (metric labels).
