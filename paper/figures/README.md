# Paper figures

Generated by `scripts/make_paper_figures.py` (one figure per positional arg).
Each writes a PNG (inspection) and a PDF (manuscript). Regenerate, e.g.:

    python scripts/make_paper_figures.py accel      # F6a
    python scripts/make_paper_figures.py jerk        # F6b
    python scripts/make_paper_figures.py smoothing   # F5
    python scripts/make_paper_figures.py spaghetti   # F7
    python scripts/make_paper_figures.py boxvstraj   # F4
    python scripts/make_paper_figures.py gtfree      # F9
